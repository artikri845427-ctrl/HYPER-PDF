# Release notes

## 1.0.0 — first release

© 2026 Anwarul Haque (@HYPERMX7). All rights reserved. | Contact: 7739399007

### Features

* PDF reader with continuous scroll view, zoom (10 % – 400 %), fit to width, fit to page,
  rotate, page navigation and a page overview.
* Full text search with a result list and highlighted hits inside the pages.
* Printing, copying of text and of a page as an image.
* Recent files, favourites and a restoreable session.
* Dark and light theme, keyboard shortcuts and a command palette.
* Explorer thumbnail provider and preview handler (x64 and x86) based on PDFium.
* Single installer with automatic registration of the Shell extensions and of the
  *Open with* entry for PDF documents.

### Known limitations

* The .NET 8 Desktop Runtime is required (the installer offers the download).
* Password protected documents need the password when they are opened.
